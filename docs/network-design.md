# ネットワーク設計

## 1. 概要

Cisco Packet Tracerを使用し、4台のルータをそれぞれ異なるASに所属させたMulti-AS構成を構築する。

eBGPを使用してAS間で経路情報を交換し、複数経路が存在する環境でのBGPの経路選択および障害発生時の経路切り替えを確認する。

## 2. ネットワーク構成

```text
PC1
 |
 | 192.168.10.0/24
 |
R1 (AS65001)
 | \
 |  \
 |   \
R2    R3
AS65002 AS65003
 |      |
 |      |
  \    /
   \  /
    R4 (AS65004)
     |
     | 192.168.40.0/24
     |
    PC2
R1からR4までの経路は以下の2経路を持つ。
R1 → R2 → R4
R1 → R3 → R4
3. AS構成
ルータ	AS番号
R1	65001
R2	65002
R3	65003
R4	65004
4. IPアドレス設計
R1
インターフェース	IPアドレス	接続先
G0/0	192.168.10.1/24	PC1
G0/1	10.0.12.1/30	R2
G0/2	10.0.13.1/30	R3
R2
インターフェース	IPアドレス	接続先
G0/0	10.0.12.2/30	R1
G0/1	10.0.24.1/30	R4
R3
インターフェース	IPアドレス	接続先
G0/0	10.0.13.2/30	R1
G0/1	10.0.34.1/30	R4
R4
インターフェース	IPアドレス	接続先
G0/0	192.168.40.1/24	PC2
G0/1	10.0.24.2/30	R2
G0/2	10.0.34.2/30	R3
5. ネットワーク一覧
ネットワーク	用途
192.168.10.0/24	PC1側LAN
192.168.40.0/24	PC2側LAN
10.0.12.0/30	R1-R2間
10.0.13.0/30	R1-R3間
10.0.24.0/30	R2-R4間
10.0.34.0/30	R3-R4間
6. BGP設計
各ルータでeBGPを設定し、直接接続している異なるASのルータとBGPネイバーを確立する。
BGPネイバー
R1 - R2
R1 - R3
R2 - R4
R3 - R4
R1は192.168.10.0/24をBGPで広報する。
R4は192.168.40.0/24をBGPで広報する。
これにより、PC1とPC2間で異なるASを経由した通信を可能にする。
7. 冗長経路
R1とR4の間には以下の2つのBGP経路が存在する。
R1 → R2 → R4
R1 → R3 → R4
通常時はBGPのベストパス選択によって1つの経路が使用され、もう一方の経路もBGPテーブルに保持される。
8. 障害試験
以下の内容を確認する。
全BGPネイバーがEstablished状態であること
R1で192.168.40.0/24への複数のBGP経路を確認する
AS_PATHを確認する
ベストパスを確認する
PC1からPC2への疎通を確認する
R1-R2間リンクを停止する
R2経由のBGP経路が消失することを確認する
R3経由へ経路が切り替わることを確認する
障害中もPC1からPC2への疎通が継続することを確認する
R1-R2間リンクを復旧する
BGPネイバーおよび経路が復旧することを確認する
